# WayGo - Smart Tourism Management System

WayGo is a MERN stack web application developed as part of a university project. It is designed to simplify and enhance the travel experience by providing users with essential tourism services in one platform. The system allows users to book hotels, rent vehicles and guides, make secure payments, and plan their trips effectively.

## Project Description

The goal of WayGo is to offer a smart, centralized tourism management system that supports travelers and tourism providers. The application includes a user-friendly interface, an admin panel for managing services, and role-based authentication to separate user and admin functionalities.

## Core Features

- Hotel booking system with wishlist functionality
- Vehicle rental management for cars, vans, and bikes
- Guide booking system with detailed profiles
- Online payment with card details and admin-side verification
- Role-based login for users and admins
- Dialogflow chatbot integration for basic queries and support
- Weather API integration to display live weather data
- Static pages like Home, Blog, Destination, and Contact

## Technologies Used

Frontend:

- Node.js

Database:

- Dialogflow for chatbot
- OpenWeatherMap API for weather

## How to Run the Project

1. Start the backend server:
   cd Backend
   npm run dev

2. Start the frontend development server in a new terminal:
   cd Frontend
   npm start

3. Open the application in your browser at http://localhost:3000
